Abstract

Emergency-vehicle access in Indian cities is limited by narrow roads and overhead obstructions invisible to 2D navigation. We segment mobile-LiDAR clouds with 3D foundation models (Sonata, Concerto, Utonia), measure effective width and overhead clearance per road section, fuse them into accessibility classes, and route accessibility-aware across Bhopal, Kerala, and Chandigarh. Because point clouds face data-sharing restrictions while model weights do not, cities share models, not data: task-vector merging builds one deployable encoder per city, with no joint retraining.

  2. Model merging as deployment

  3. Accessibility-aware navigation

Method

Robust geometric measurement

Width and clearance are read directly from the segmented points by two independent pipelines that fuse only at the end — one ruler everywhere (the occupancy-bin robust cross-section), reported conservatively, because accessibility binds on the tightest point.

① Carriageway width

horizontal constraint · measured from the segmented road points
1 · CLEAN
Point cleaning (deployment only)
Three detach-guarded passes; survey GT stays raw.
2 · BOUNDARY
Class-aware outline
α-hull + class-aware holes; a median splits divided roads (GT IoU 0.965).
3 · CENTERLINE
Point-based spine
Occupancy-raster topology; routable main spine vs branch arms.
4 · JUNCTIONS
Orientation-field detection + typing
Found and typed from the road director field; interiors masked.
5 · WIDTH
One-ruler per-station width
Robust cross-section per station; branch arms & leaf tips = WU, never a block, never routed.
Step 4 — orientation-field junction detection & typing
Local-PCA director field θ→ Stick saliency + multi-scale nematic order ℛ (1−ℛ)→ Poincaré charge q (±½ = T/Y, ±1 = 4-way / rotary)→ Confirm ≥ 3 road arms→ Type: T/Y · + · X · rotary, template-refined

② Overhead clearance

vertical constraint · measured from the above-road points
1 · DATUM
Road-surface datum
Per-station ground plane — the reference for every clearance.
2 · STREAMS
Semantic streams
Wire · vegetation · structure · catch-all; buildings never bind.
3 · GATHER
Road-aligned box
±1.5 m slab clipped to the carriageway; one cylinder per junction.
4 · ISOLATION
Outlier filter
> 2 neighbours in 0.8 m — drops birds, dust, single-beam ghosts.
5 · PER-STREAM
Stream clearance
5th-percentile height; wires add a catenary sag fit.
Step 6 — binding clearance
γ = min(wire, vegetation) structure & catch-all stay as separate flags; every reading records its responsible class + evidence count (bind_n)
→ binned to the clearance class H0 H1 H2 H3
